# Auroria Toolkit

Unofficial fan-made tools for ArcheAge Chronicles.

## Tools

- **Warrior Stat Planner:** plan your stat points from level 1 to 40, see which weapon sets your Talent target, and compare Longsword and Greatsword damage.
- **Crafting Calculator:** work out the materials and gold a recipe needs. Planned; recipe data is not available yet.

Both tools are in development. This page will become the user guide.
